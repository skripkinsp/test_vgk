# EXPERIMENTS — журнал гипотез и решений

**Правило:** указанные ниже значения взяты из действительно выполненных и сообщённых прогонов; неизвестные метрики не заменяются оценками «на глаз». Отложенный период ETA просматривался более одного раза — это ограничивает независимость итогового сравнения. Итоговый 21-дневный causal-эксперимент после последней структурной правки пока не зарегистрирован.

| Этап / гипотеза | Изменение | Наблюдения и метрика | Решение |
|---|---|---|---|
| Генератор должен содержать причины задержек, а не только случайный шум | Сетка 30×40, 50 м, ~200 узлов, три погрузки и две разгрузки; дождь/влажность/уклоны/нагрузка/водители/очереди/поломки/трафик | 21-дневные генерации давали ~40 тыс. поездок и ~20 тыс. рекомендаций | Зафиксировали событийную модель и строгий формат CSV |
| Простая Дейкстра с постоянной скоростью — слабый ETA baseline | `src/baseline.py`: 30 км/ч пустой, 20 км/ч гружёный, p90=1.25 p50 | Совпадает с указанной формулой baseline | Использовать как обязательную отправную точку |
| Нормативные альтернативные маршруты и историческая скорость должны улучшать ETA | `features.py`: до 5 путей Йена; длины, покрытия, уклоны, трафик, наблюдаемая скорость, погодные признаки | 72 признака, обучение и single-request prediction работают | Оставить общую функцию формирования признаков для train/predict |

| ML-инференс должен выдерживать 10 мс на запрос | Переиспользуем `RoadContext`, модели и кэш маршрутов; fallback | На локальном **повторении одного запроса**: 300 вызовов, hot p50=5.1684 мс, p95=5.8259 мс, first cold=50.2025 мс, max=34.4357 мс, fallback=0 | Считаем доказанной только прогретую однотипную нагрузку, не весь SLA |
| Snapshot-разность времени маршрутов — плохая приватная causal truth | Первоначальная `truth/effect.json` строилась из номинального маршрута/очереди, не из парных потенциальных исходов | На одном наборе AIPW около −105 с при прежней приблизительной истине около −255 с; интерпретация нестрогая | Изменили causal-конструкцию; эти числа **не сравнивать** с финальным структурным ATT |
| Общий residual, восстановленный **после** фактического решения, даст причинную истину | `Y(0),Y(1)` конструировались из наблюдаемого `outcome_s` | Первая 5×21-дневная проверка: **MAE AIPW 130.095 с, MAE naive 214.906 с, покрытие 0/5** | Гипотеза отвергнута; найдено пострешенческое определение приватной истины |
| Удаление скрытого confounding из propensity решит расхождение | Приём по публичным признакам, но потенциальные исходы всё ещё определялись через post-treatment residual | Вторая 5×21-дневная проверка: **MAE AIPW 152.643 с, MAE naive 255.141 с, покрытие 0/5** | Гипотеза отвергнута: одной правки механизма принятия недостаточно |

## Использование holdout

Разделение — по времени; обучение включает только поездки, **завершённые** до `UNTIL`. Внутри исторического отрезка выделяется временная валидация. Внешний ориентир по исходному набору: `2025-09-19 03:00 UTC` — `2025-09-22 03:00 UTC`.

Последние три дня **уже использовались неоднократно** для сравнения и диагностики CatBoost: пользователь анализировал выигрыш на срезах и последние 2–4% запросов, где baseline лучше. Точное количество запусков неизвестно. Поэтому данный период нельзя называть строго нетронутым для дальнейшего выбора архитектуры. После первых результатов ETA **не тюнировалась целенаправленно по holdout**; добавлялась в основном инфраструктура оценки/предсказания. Если нужна независимая проверка после всех изменений, следует зафиксировать параметры и оценить их на новом наборе.

## Невыполненные эксперименты и ограничения

- Отдельная абляция маршрутов, истории, погоды и `driver_id` **не проводилась**.
- Взвешенный physics baseline (время по поверхности/уклонам/модели) **обсуждался, но не реализован**.
- Подтверждённый разрез поломок невозможен без дополнительной метки в публичных событиях.
- Интервал AIPW получен дневным кластерным bootstrap при фиксированных nuisance-моделях; при иных данных может быть недопокрытие.
- Значение `est_gain_s` преднамеренно смещено; оценку следует брать из `effect_validation.csv` конкретной версии данных. Для 4-дневных финальных проверок среднее смещение на принятых рекомендациях: **+113.187 с** в принятой конвенции `est_gain_s + (Y1−Y0)`.

**Итоговое решение:** не добавлять новые модели/нейросети; зафиксировать честно измеренные метрики, восстановить обязательный CLI и завершить документацию.
